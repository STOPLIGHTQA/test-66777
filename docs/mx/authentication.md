## OAuth2.0 
Access token is an entity that applications use to make API requests on behalf of a user. The access token represents the authorization of a specific application to access specific parts of a user’s data.

 - OAuth 2.0 can support authentication/authorisation of a user against a resource (e.g. a service) for specific client applications. This allows permissions to be revoked for an individual user, or for a client (e.g. disabling a rogue mobile application).

 - OAuth authentication (resource server) – Authorization HTTP header is present and specifies authorisation type of ‘Bearer’, indicating that the Authorization contains a bearer access token
